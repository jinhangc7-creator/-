## 怎么读

- **不用全做**：这是一份按人生阶段排好的备选单，不是任务清单。挑走一两条就算数，剩下的放着，需要时再回来查。
- **想按条件挑**：打开[在线阅读页](https://jinhangc7-creator.github.io/anwenrensheng/)，可以按关键词、证据等级 A/B/C 来筛。页面内容直接取自 `book/` 目录里的正文，正文一改，页面跟着改。
- **每条都有一行「说人话」**：它把「收益」栏里那些文件、数据里的写法，翻成日常说法。只看这一行就够拿主意；想自己核对，就看「收益」栏里的原文和数字。
- **只想看结论最硬的**：在阅读页里只勾 A 级，留下 103 条有具体数字、引到法条原文或官方文件的条目。
- **条目之间会互相指路**（「见第 8 节第 17 条」这种）：在 GitHub 上直接读正文时，每处指路后面都写清了指向哪一条，不翻过去也知道说的是哪条。

每条建议长这样：

```markdown
### 1. 先签合同再干活，不签合同干满一个月，公司要赔你双倍工资
- 成本：不花钱。要求签合同多花 10 分钟，把合同自己留一份。
- 说人话：上班第一天就要签书面劳动合同，这是法律规定的，不是什么"转正再签""干满三个月再签"。公司如果超过一个月还不跟你签，从第二个月起要付你双倍工资，最多赔 11 个月。
- 收益：《劳动合同法》第十条：建立劳动关系，应当订立书面劳动合同……第八十二条：用人单位自用工之日起超过一个月不满一年未与劳动者订立书面劳动合同的，应当向劳动者每月支付二倍的工资。
- 证据等级：A
- 来源：《中华人民共和国劳动合同法》第十条、第八十二条。国家法律法规数据库 flk.npc.gov.cn 可查全文。
- 备注：口头承诺、微信里说的都不算数，以纸质合同为准。
```

## 证据分级

每条建议都标注证据等级：

| 等级 | 含义 |
| --- | --- |
| A | 有具体数字可查：引到法律条文、官方文件原文，或国家统计局等官方机构发布的数据，能说出降了多少、差了多少 |
| B | 有依据，但说不出一个确切数字；或依据是媒体对官方数据的转述，已注明转述链条 |
| C | 经验法则、大家公认的做法，没有直接的硬数据支撑 |

全书 587 条中 A 级 103 条、B 级 266 条、C 级 218 条。A 级只说明「有具体出处、可核查」，不说明这个结论放之四海皆准——收益栏里写了数据口径和适用人群，先看那一栏再套用到自己身上。
