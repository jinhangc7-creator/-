# 安稳人生指南

**18 岁到退休，农村县城城市三选一，选出最安稳的那条路。**

不教你暴富，不教你躺赢。这本书只回答一个问题：普通人怎么少踩坑、少花冤枉钱、少走弯路，安安稳稳地过完一生。

> 36 节 · 587 条建议 · 每条写明花掉什么、换回什么、证据有多硬 · 来源只引官方文件、统计数据和期刊论文

## 证据分级

- **A 级**：法律原文、国家统计局/部委文件、期刊论文，可逐字核对
- **B 级**：权威机构监测数据、权威媒体转述官方数据
- **C 级**：经验法则，已明示"证据弱"，仅供参考

每条格式：成本 / 说人话 / 收益 / 证据等级 / 来源 / 备注。数字都带出处链接，欢迎核查指正。
